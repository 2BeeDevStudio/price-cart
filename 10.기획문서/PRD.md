# PriceCart 기획서

쇼핑 중 카트에 담은 물건의 총 결제 예상 금액을 실시간으로 계산하는 앱.
마트·다이소·코스트코 등에서 가격표만 촬영하면 OCR로 가격을 인식해 합계를 보여준다.

## 개발 방향

- 플랫폼: **웹앱(PWA)** 로 시작 (개인용 · 앱스토어 등록 없이 홈 화면 설치)
- OCR: **온디바이스(Tesseract.js)** — 무료 · 오프라인 · 서버 불필요
- V1 은 최대한 단순하게: 상품 DB 없음, 회원가입 없음, 가격만 읽기, 오늘 쇼핑 금액 계산에 집중

---

## V1 기능

1. **홈** — 총 예상 결제금액, 총 상품 개수, 상품 목록, 하단 `+ 상품 추가` 버튼
2. **상품 추가** — 카메라로 가격표 촬영 → OCR 로 가격 인식 → 결과 확인/수정 → 확인 또는 다시 촬영
3. **상품 정보** — `가격`, `수량` 만 저장. 상품명은 저장하지 않음
4. **수량 변경** — 기본 1개, `− 1 +` 로 조절 (예: `980원 × 4개`)
5. **총 금액** — 모든 상품 `가격 × 수량` 합계를 상단에 항상 표시, 추가/변경/삭제 시 즉시 갱신
6. **상품 삭제** — 목록에서 삭제, 총액 즉시 재계산

### OCR 요구사항

- 숫자/가격 인식에 집중 (상품명 인식은 불필요)
- 인식 대상 예: `1,980` `1980` `₩1,980` `1,980원` `1980원`
- 쉼표 제거 후 정수로 저장 (`1,980` → `1980`)

### 데이터 구조

```
Item { id, price, quantity, createdAt }
```

## V2 (추후)

1. **상품 정보 연결** — 가격표만 찍어도 상품명 인식, DB 매칭 시 이미지·상품명·브랜드 표시
2. **영수증 OCR** — 결제 후 영수증 촬영 → 상품별 데이터 자동 저장
3. **구매 이력** — 상품 상세에서 최근 구매 일자·가격 목록
4. **가격 비교** — 같은 상품의 가격 변화 표시 (현재가 vs 지난 구매, 등락률)
5. **할인 분석** — 최저가·최고가·평균가·현재 할인율 계산

---

## 기술 스택 (V1 확정)

- Frontend: Vite + React + TypeScript
- OCR: Tesseract.js (온디바이스)
- Storage: localStorage (로컬만, 오프라인)
- 상태관리: Zustand
- UI: Tailwind CSS
- PWA: 수동 Service Worker + manifest (오프라인 · 홈 화면 설치)

## MVP 개발 원칙

- 핵심 가치: "사진 한 장 → 가격 자동 인식 → 총액 계산"
- V1 에서는 회원가입·서버·상품 DB·구매 이력·통계 제외
- 오프라인 우선 구조
- V2 기능은 단계적으로 추가
