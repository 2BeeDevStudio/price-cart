# PriceCart 사용설명서

쇼핑 중 가격표를 촬영하면 총 결제 금액을 미리 계산해 주는 앱.
주소: **https://pricecart.2bee.dev**

---

## 0. 설치 (앱처럼 쓰기)

1. 휴대폰 브라우저로 `pricecart.2bee.dev` 접속
2. **홈 화면에 추가**
   - 아이폰(Safari): 공유 버튼 → "홈 화면에 추가"
   - 안드로이드(Chrome): 메뉴(⋮) → "홈 화면에 추가"
3. 홈 화면 아이콘으로 실행하면 전체화면 앱처럼 동작해요.

> ⚠️ **한 곳에서만 쓰세요.** 저장 데이터는 기기·브라우저마다 따로예요. 홈 화면 앱과 브라우저 탭은 데이터를 공유하지 않으니, **홈 화면 앱 하나로** 쓰는 걸 권장해요. (옮기려면 아래 "백업/복원" 참고)

---

## 1. 홈 화면 한눈에 보기

- **오늘 쇼핑 · 마트 이름** — 탭하면 마트 선택(코스트코·이마트 등, 직접 입력도 가능)
- **총 예상 결제금액** — 담은 상품의 실제 결제 예상액 (행사·수량 반영)
- **상품 N개 / 절약 금액** — 담은 개수와 행사로 아낀 금액
- **예산** — 정해두면 진행 막대와 남은 금액이 표시
- 우측 상단 **기록**(목록 아이콘), **비우기**(휴지통)
- 하단 **＋ 상품 추가**, **🛒 쇼핑 끝**

---

## 2. 상품 추가 (촬영 → 자동 인식)

1. 하단 **＋ 상품 추가** → **카메라 열기**
2. 가격표를 촬영하면 자동으로 **가격·상품명**을 인식해요.
3. 결과 화면에서 확인/수정:
   - **상품명** — 자동 추측값이 들어와요 (틀리면 고치거나 비워도 됨)
   - **가격** — 인식된 값. 다르면 아래 **후보 숫자 칩**을 탭하거나 직접 수정
   - **행사** — 일반 / **1+1** / **2+1** 선택
4. **확인**을 누르면 목록에 담겨요. (다시 촬영·직접 입력도 가능)

### 잘 인식되게 찍는 팁
- 가격 숫자가 **화면에 크게** 차도록 가까이
- 밝은 곳에서, 정면으로, 흔들림 없이
- 반사·구겨짐이 심하면 후보 칩이나 직접 입력으로 보정

> 인터넷이 되면 정확한 클라우드 인식, 안 되면 자동으로 기기 인식으로 전환돼요.
> (기기 인식일 땐 한글 상품명을 잘 못 읽어서 "오프라인·기기 인식" 배지가 떠요.)

---

## 3. 상품 관리

- **수량 조절** — 상품 우측 `−` / `+`
- **이름·가격·행사 수정** — 상품을 **탭**하면 편집 창 (연필 아이콘 표시)
- **삭제** — 우측 휴지통 아이콘
- 총액·절약·예산은 바뀔 때마다 **즉시 갱신**

### 행사(1+1 / 2+1) 계산
- **1+1**: 2개 담으면 1개 값만 결제 (3개면 2개 값…)
- **2+1**: 3개 담으면 2개 값만 결제
- 상품에 **행사 배지**와 원가 취소선·절약액이 표시돼요.

---

## 4. 예산

- 히어로 카드의 **예산 설정하기** → 프리셋(3만~20만) 또는 직접 입력
- 담을수록 **진행 막대**가 차고 **남은 금액**이 줄어요.
- 상태 색: 여유 / 임박 / **초과**(초과 금액 표시)
- 예산은 선택 사항 — 안 정하면 그냥 총액만 보여줘요.
- 수정: 막대나 "예산 …" 텍스트를 다시 탭

---

## 5. 쇼핑 끝 · 기록 저장

1. 상품을 다 담고 (마트·예산도 정해두면 좋아요)
2. 하단 **🛒 쇼핑 끝 · 기록 저장** → 확인
3. 오늘 목록이 **기록으로 저장**되고 카트가 비워져요 (새 쇼핑 시작)

---

## 6. 지난 쇼핑 기록

우측 상단 **기록** 버튼 → 지난 쇼핑 목록

- 각 항목: **날짜 · 마트 · 합계 · 개수** (탭하면 상품 목록 펼침)
- 펼친 상세에서:
  - **🏬 마트 수정** (마트 없이 저장한 것도 나중에 지정 가능)
  - 상품 **수량 ± / 삭제**, 상품 **탭해서 이름·가격·행사 수정**
  - **예산 달성/초과**, **절약액** 표시
  - **기록 전체 삭제**

---

## 7. 백업 / 복원

기록 화면 우측 상단 **백업 / 복원**

- **📤 기록 내보내기** — 백업 파일(JSON) 저장
  - 아이폰: 공유 시트 → **"파일에 저장"**
- **📥 기록 불러오기** — 저장한 파일 선택 → 기록 **병합**(중복 없음, 기존 유지)

### 다른 곳으로 옮기기 (예: 브라우저 → 홈 화면 앱)
1. 기존 기록이 있는 곳에서 **내보내기** → 파일에 저장
2. 옮길 앱(홈 화면 앱)에서 **불러오기** → 그 파일 선택
3. 완료. 이후엔 한 곳에서만 사용

> 가끔 **내보내기로 백업**해두면 기기를 바꿔도 안전해요.

---

## 8. 데이터 · 개인정보

- 모든 데이터는 **기기 로컬(브라우저 저장소)**에만 저장돼요. 서버·회원가입 없음.
- 오프라인에서도 계산·기록이 동작해요.
- 촬영 사진은 **가격/글자 인식**을 위해 Google Vision으로 전송돼 텍스트만 받아와요 (사진은 저장하지 않음).

---

## 9. 자주 겪는 상황

| 상황 | 해결 |
|---|---|
| 상품명이 영어로만 나옴 | "오프라인·기기 인식" 상태예요. 인터넷 연결 후 다시 촬영 |
| 가격이 이상하게 인식됨 | 후보 칩 탭 또는 직접 수정. "인식 원문 보기"로 확인 가능 |
| 홈 화면 앱에 기록이 비어있음 | 저장소가 분리돼서 그래요. 백업/복원으로 옮기기 |
| 새 기능이 안 보임 | 새로고침 (서비스워커라 한 번 더 필요할 수 있음) |
