# PriceCart V2 상세 기획 — 가격 기록 & 구매 도우미

V1(가격표 촬영 → 총액 계산)에서 **"가격 기록 및 구매 도우미"**로 확장한다.
영수증 OCR과 구매 이력 데이터가 쌓일수록 가치가 커지는 구조.

> 앞선 V2 기본 항목(상품명 인식, 영수증 OCR, 구매 이력, 가격 비교, 할인 분석)은 `PRD.md` 참고.
> 이 문서는 그중 **구매 비교/분석/추천** 기능을 상세화한 것.

## 6. 과거 구매 비교

상품 인식 시 과거 구매 이력이 있으면 자동으로 비교 정보를 표시한다.

- 상품 카드에 **비교 배지** 표시
  - `🟢 이전 구매 이력 있음`
  - `📊 가격 비교 가능`
- 상품 선택 시 상세 표시

**단일 이력 예시**
```
코카콜라 1.5L
현재 판매가  2,980원
────────────
최근 구매
구매일     2026-05-10
정가       3,480원
할인가     2,980원
할인율     14%
최종 구매가 2,980원
```

**복수 이력 예시**
```
최근 구매 이력
2026-05-10 · 정가 3,480원 · 14% 할인 · 2,980원 구매
2026-03-18 · 정가 3,280원 · 10% 할인 · 2,950원 구매
2025-12-22 · 정가 3,580원 · 1+1 행사 · 3,580원 구매
```

## 7. 가격 변동 분석

과거 이력 기반으로 현재 가격이 유리한지 알려준다.

**저렴할 때**
```
✅ 평소보다 500원 저렴합니다.
최근 평균 구매가  3,480원
현재 가격        2,980원
약 14% 저렴
```

**비쌀 때**
```
⚠️ 예전에 더 저렴하게 구매한 적이 있습니다.
최저 구매가  2,480원
현재 가격    2,980원
500원 더 비쌉니다.
```

## 8. 구매 추천 알림

카트에 담는 순간 간단한 구매 가이드 제공.
- `🟢 지금 사도 좋은 가격입니다.`
- `🟡 평균 가격 수준입니다.`
- `🔴 최근 구매보다 비쌉니다.`

판정 기준(안): 현재가 vs 최근 평균/최저가 비교로 신호등 결정.

## 추가 데이터 구조

V2부터 영수증 OCR로 아래를 저장한다.

```ts
interface PurchaseHistory {
  id: string
  productId: string
  purchaseDate: string   // 구매일
  originalPrice: number  // 정가
  discountPrice: number  // 할인 금액
  discountRate: number   // 할인율(%)
  finalPrice: number     // 실제 결제 금액
  quantity: number
  receiptId: string
}
```

- `productId`: 상품 식별 (상품명 인식/DB 매칭 결과와 연결)
- `receiptId`: 영수증 단위 묶음

## V2.5 ~ V3 확장 아이디어

- **가격 히스토리 그래프**: 상품별 가격 변동 선 그래프
- **최저가 알림**: "지금까지 구매한 가격 중 가장 저렴합니다."
- **행사 유형 분석**: 1+1, 2+1, % 할인, 즉시 할인 구분 기록
- **구매 주기 분석**: "이 상품은 평균 38일마다 구매합니다."
- **마트별 가격 비교**: 이마트·홈플러스·코스트코 등 매장별 평균 구매가 비교

목표: 단순 계산 앱 → **내 소비 데이터 기반 개인 가격 비서**.

## 구현 시 고려사항 (메모)

- **상품 식별 문제**: 과거 비교는 "같은 상품"을 알아야 성립 → 상품명 인식 + 정규화/매칭 로직이 선행되어야 함 (V2의 상품명 인식과 강결합).
- **저장소**: 이력이 쌓이면 localStorage 한계 가능 → IndexedDB 전환 검토.
- **영수증 OCR**: 상품명·수량·정가·할인·최종가 파싱 (Vision DOCUMENT_TEXT_DETECTION 등 활용).
